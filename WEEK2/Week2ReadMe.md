## Overview

This week focuses on practicing Python loops, reusable functions, problem-solving techniques, and input validation.

The objective is to develop small Python programs using meaningful variable names, structured code, and proper validation of user input.

## Tasks Completed

### 1. Sum of Numbers



Calculates the sum of all integers from 1 to a user-provided positive integer using a loop and a reusable function.

**Concepts used:**
- For loop
- Functions
- Return values
- Input validation
- Exception handling

### 2. Multiplication Table


Takes a number from the user and displays its multiplication table from 1 to 10.

**Concepts used:**
- For loop
- Functions
- Function parameters
- Formatted strings
- Input validation

### 3. Factorial Calculator


Calculates the factorial of a non-negative integer using a loop.

**Concepts used:**
- For loop
- Functions
- Accumulator
- Return values
- Input validation

### 4. Number Guessing Game


A number guessing game in which the computer generates a random number between 1 and 20. The user continues guessing until the correct number is found.

The program provides hints when the guess is too high or too low and counts the number of attempts.

**Concepts used:**
- While loop
- Conditional statements
- Random module
- Break and continue
- Input validation
- Attempt counter

### 5. Simple Calculator


A simple calculator that performs addition, subtraction, multiplication, and division using separate reusable functions.

The program validates numeric input, checks the operator, and handles division by zero.

**Concepts used:**
- Functions
- Parameters and return values
- Conditional statements
- Input validation
- Exception handling
